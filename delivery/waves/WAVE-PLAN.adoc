= Carting Wave Plan

== Wave 1

Component skeleton, composer, bundle, DI, configuration, docs, delivery surface.

== Wave 2

Core Doctrine entities and repositories: Cart, CartItem, CartAdjustment, CartCheckoutHandoff.

== Wave 3

Core services: mutation, summary, merge, token, checkout preparation.

== Wave 4

External Symfony-oriented service interfaces for offer snapshot, availability, checkout consumer, and UI surface.

== Wave 5

HTTP/API/Form surface: cart display, add/update/remove items, checkout entry.

== Wave 6

Checkout handoff payload and persistence boundary toward Ordering.

== Wave 7

Outgoing UI surface contract plus non-destructive Interfacing template draft files.

== Wave 8: Checkout readiness and lifecycle hardening

Adds active-cart lifecycle guards, checkout-readiness validation, and explicit estimate provider interfaces for pricing, tax, and promotion integrations.

== Wave 10: Singular-word template resolution

Replaces the old Carting-to-Interfacing bridge draft with a minimal singular-word surface model. Carting exports `word=cart`, `view=summary`, template candidates under `templates/cart/`, and named slots that can be rendered by a specialized template or by same-folder data fallback rendering.

Touched areas:

* `src/Provider/CartSurfaceProvider.php`
* `src/Factory/CartSurfaceContractFactory.php`
* `src/ServiceInterface/CartSurfaceProviderInterface.php`
* `src/Contract/CartSurfaceContract.php`
* `integration-draft/Interfacing/templates/cart/*`
* `tests/Unit/Service/CartSurfaceContractFactoryTest.php`
* `docs/architecture/carting-output-surface-contract.adoc`


== Wave 12 - Cart single-folder surface final seal

Finalizes the Carting producer-side example around one singular business word and one template folder. Carting exports `word=cart`, `view=summary`, named slots, and same-folder template paths under `templates/cart/`. No plural folder, generic folder, namespace path, or component-specific bridge path participates in rendering.

Touched areas:

* `docs/architecture/carting-output-surface-contract.adoc`
* `delivery/waves/WAVE-PLAN.adoc`

Removed stale local wave marker files from the cumulative slice so simple drift scans no longer report deleted plural/generic/bridge paths as active repository content.
